# OpenEntry

An open entry is a <glossary:DayEntry> or <glossary:TaskEntry> that is not linked to a closed <glossary:TimesheetSubmission>. A TaskEntry inherits this state through its DayEntry.

Open entries can be created, edited or deleted by users with the required permissions only when no later closed timesheet exists for the same resource. If a later timesheet is closed, that submission must be reopened first.
