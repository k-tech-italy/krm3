# TaskEntry

_Django Model: core.TaskEntry_

TaskEntry is a <glossary:TimeEntry> with a specified Task and it represents work on a particular task (e.g., shift, travel, on-call duty).

### TaskEntry may include:
- day shift hours
- night shift hours
- travel hours
- on call hours
